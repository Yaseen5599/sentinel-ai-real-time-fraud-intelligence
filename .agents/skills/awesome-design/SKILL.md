# Awesome Design Systems (VoltAgent/awesome-design-md)

Curated design systems, component specifications, and UI tokens extracted from world-class developer and financial tools to guide agents in generating cohesive, high-craft, professional web interfaces.

## Core Design Principles

1. **Software-Craft Aesthetic**: Avoid default unstyled borders, generic saturated colors, and boilerplate templates. Use measured negative letter spacing, tight hairline borders, and intentional accent color accents.
2. **Cohesive Color Polarity**: Deep near-black canvases (`#010102` to `#0f1011`) for technical security and fraud dashboards, or crisp light canvases with high-contrast slate/navy ink.
3. **Tabular Numerics**: Always use `font-variant-numeric: tabular-nums` or monospace numbers for money, percentages, scores, and timestamp metrics.

## Design Reference Profiles

- **Linear Style** ([Linear Reference](./references/linear.md)):
  - Deep dark canvas (`#010102`), charcoal cards (`#0f1011`), hairline borders (`#23252a`).
  - Lavender chromatic accent (`#5e6ad2`), light gray text (`#f7f8f8`), tight negative tracking on headlines.
  - Best for: Technical security dashboards, real-time analytics, developer command centers.

- **Stripe Style** ([Stripe Reference](./references/stripe.md)):
  - Deep navy ink (`#0d253d`), electric indigo primary (`#533afd`), subdued hairline dividers (`#e3e8ee`).
  - Best for: Payment flows, transaction tables, financial trust indicators, merchant statistics.

- **Supabase Style** ([Supabase Reference](./references/supabase.md)):
  - Emerald green accent (`#3ecf8e`), dark slate night mode (`#1c1c1c`), clean humanist display type.
  - Best for: Database status, API metrics, connection status indicators, infrastructure logs.
