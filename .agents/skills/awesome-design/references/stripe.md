# Stripe Design Reference (VoltAgent/awesome-design-md)

Financial infrastructure design language built around deep navy ink, electric indigo, tabular figures, and crisp clarity.

## Color Tokens
- **Primary**: `#533afd` (electric indigo)
- **Primary Deep**: `#4434d4`
- **Primary Soft**: `#665efd`
- **Ink (Text Main)**: `#0d253d` (deep navy ink)
- **Ink Secondary**: `#273951`
- **Ink Muted**: `#64748d`
- **Canvas**: `#ffffff`
- **Canvas Soft**: `#f6f9fc`
- **Hairline Divider**: `#e3e8ee`
- **Hairline Input Border**: `#a8c3de`
- **Ruby (Danger)**: `#ea2261`
- **Success**: `#00d924`

## Typography Guidelines
- Tight display weights with negative letter-spacing for editorial density.
- Tabular figures (`font-variant-numeric: tabular-nums`) strictly enforced for monetary amounts and transaction counts.
- Clear distinction between metadata labels (muted uppercase 11-12px) and values (bold tabular 14-18px).

## Component Styling Rules
- **Pills and Badges**: Subtle tinted background (e.g. rgba of status color + 0.1), dark text, rounded-full.
- **Data Tables**: Clear header separation, subtle horizontal row dividers (`#e3e8ee`), alternate row hover highlight (`#f6f9fc`).
