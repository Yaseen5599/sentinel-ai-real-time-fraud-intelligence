# Linear Design Reference (VoltAgent/awesome-design-md)

A near-black product-focused marketing canvas built around #010102, light gray text (#f7f8f8), and the signature Linear lavender-blue (#5e6ad2) used as the single chromatic accent. Dense, technical, and quietly luxurious.

## Color Tokens
- **Canvas**: `#010102` (deepest dark surface)
- **Surface 1 (Cards/Panels)**: `#0f1011`
- **Surface 2**: `#141516`
- **Surface 3**: `#18191a`
- **Primary / Accent**: `#5e6ad2`
- **Primary Hover**: `#828fff`
- **Primary Focus**: `#5e69d1`
- **Ink (Text Main)**: `#f7f8f8`
- **Ink Muted**: `#d0d6e0`
- **Ink Subtle**: `#8a8f98`
- **Ink Tertiary**: `#62666d`
- **Hairline Border**: `#23252a`
- **Hairline Strong**: `#34343a`
- **Semantic Success**: `#27a644`
- **Semantic Warning / Alert**: `#f2994a`
- **Semantic Danger / Critical**: `#eb5757`

## Typography Guidelines
- Display XL: 80px / 1.05 line-height / -3.0px letter-spacing (semi-bold 600)
- Display LG: 56px / 1.10 line-height / -1.8px letter-spacing
- Display MD: 40px / 1.15 line-height / -1.0px letter-spacing
- Headline: 28px / 1.20 line-height / -0.6px letter-spacing
- Card Title: 22px / 1.25 line-height / -0.4px letter-spacing
- Body LG: 18px / 1.50 line-height / -0.1px letter-spacing
- Body (Standard): 16px / 1.50 line-height / -0.05px letter-spacing
- Body SM: 14px / 1.50 line-height / 0 letter-spacing
- Caption / Eyebrow: 12px / 1.40 line-height / 0 letter-spacing

## Radiuses & Spacing
- Radiuses: `xs: 4px`, `sm: 6px`, `md: 8px`, `lg: 12px`, `xl: 16px`, `pill: 9999px`
- Component Spacing: `xs: 8px`, `sm: 12px`, `md: 16px`, `lg: 24px`, `xl: 32px`

## Component Styling Rules
- **Buttons**:
  - Primary: Background `#5e6ad2`, text `#ffffff`, radius `8px`, padding `8px 14px`.
  - Secondary: Charcoal background `#0f1011`, hairline border `1px solid #23252a`, text `#f7f8f8`, hover surface `#141516`.
- **Cards & Data Containers**:
  - Background `#0f1011`, border `1px solid #23252a`, rounded `12px`.
  - Inner items separated by `1px solid #23252a` hairlines.
