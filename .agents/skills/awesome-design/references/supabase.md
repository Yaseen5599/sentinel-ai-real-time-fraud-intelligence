# Supabase Design Reference (VoltAgent/awesome-design-md)

An open-source database and cloud platform design language: minimal chrome, clean near-monochrome palette, emerald green accent, and developer-first data components.

## Color Tokens
- **Primary / Brand Accent**: `#3ecf8e` (emerald green)
- **Primary Deep**: `#24b47e`
- **Primary Soft**: `#4ade80`
- **Dark Canvas (Night Mode)**: `#1c1c1c`
- **Dark Surface Soft**: `#202020`
- **Dark Border**: `#2e2e2e`
- **Light Canvas**: `#ffffff`
- **Light Canvas Soft**: `#fafafa`
- **Text Ink**: `#171717`
- **Text Muted**: `#707070`
- **Text On Dark**: `#ffffff`

## Component Styling Rules
- **Indicator Dots**: 8px green `#3ecf8e` pulsing dot for healthy/active services, amber `#ffdb13` for degraded, red `#ff2201` for offline.
- **Monospace Code Snippets**: Dark container `#141414`, subtle border `#282828`, clear copy action.
- **Form Controls**: Crisp dark borders with `#3ecf8e` ring on focus.
